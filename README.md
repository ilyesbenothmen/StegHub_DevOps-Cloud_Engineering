# StegHub DevOps & Cloud Engineering

This repository documents hands-on projects completed during the StegHub DevOps and Cloud Engineering bootcamp. It serves as a structured portfolio of practical work across Linux administration, web stack deployment, automation, infrastructure, containers, and version control.

## Repository Purpose

The goal of this repository is to:

- Track weekly bootcamp projects and technical exercises.
- Document deployment steps, configurations, and outcomes.
- Showcase practical experience with DevOps and cloud engineering tools.
- Build a public portfolio of reproducible infrastructure and application projects.
